Features - Pokémon Johto Classic
This document outlines the core features, technical improvements, and custom mechanics included in this hack ROM.
🌟 General & Quality of Life (QoL) Features
 * Expanded Bag System: Separate pockets for items, key items, TMs/HMs, and Poké Balls, matching modern standards.
 * Running Shoes: Hold the B button to run both indoors and outdoors for faster navigation across Johto and Kanto.
 * Reusable TMs: Technical Machines (TMs) can be used infinitely, eliminating the need to grind for specific moves.
 * Updated Type Chart & Mechanics: Incorporates modern physical/special split mechanics and balanced move pools.
 * Expanded Move Remewer & Tutor: Easier access to move relearners to customize your team's strategy on the fly.
 * Dynamic Time and Clock System: Full integration with the real-time clock (RTC) for day, night, and morning specific wild encounters and events.
 * Fast Text and Battle Speed Options: Enhanced option settings to streamline dialogue pacing and speed up repetitive battles during grinding.
 * Modernized Status & UI Feedback: Improved battle interface elements for a smoother and faster gameplay loop.
🛠️ Custom Content & Mechanics
 * Custom NPCs & Lore: Integration of unique characters, flavor texts, and specialized dialogue events (including custom overworld sprites mapped to GBC technical limitations).
 * Advanced Scripting: Enhanced map triggers, custom cutscenes, and expanded event flags using modern pokecrystal assembly standards.
 * Expanded Overworld Sprites: Custom 16x192 vertical frame-sheet support for unique player and NPC animations, matching multi-frame movement sequences.
 * Custom Region Routing & Mapping: Redesigned map layouts and expanded route events to optimize flow and introduce hidden secrets.
 * Expanded Trainer Rosters & Rematches: Fine-tuned trainer teams, adjusted levels, and updated phone call rematch systems for extra challenge.
 * Custom Map Events & Scripts: Tailored map constants and optimized event flags for dynamic interactions across every city and route.
⚙️ Technical Enhancements
 * Optimized Assembly Engine: Built directly on the latest stable pokecrystal source code repository, ensuring high performance on original Game Boy Color hardware and emulators.
 * Strict Color & Tile Limits: Fully respects GBC hardware constraints (4-color palette limit per sprite, 16x32 standard tile-mapping rules).
 * Modular Codebase: Cleanly organized map scripts, event constants, and text pointers for effortless expansion and debugging.
 * Expanded RAM and WRAM Allocation: Optimized memory usage to support new scripts, flags, and expanded data structures without crashing the stack.
 * Robust Git & Build Pipeline Integration: Designed for clean compatibility with make clean and make workflows via safe terminal environments.
